# 我的博客

一个基于静态 HTML/CSS 的个人博客网站。

## 功能特性

- 响应式设计，支持移动端浏览
- 现代化的视觉风格
- 文章列表展示
- 文章归档功能
- 关于页面

## 技术栈

- HTML5
- CSS3
- Google Fonts

## 文件结构

```
.
├── index.html          # 首页
├── about.html          # 关于页面
├── archive.html        # 归档页面
├── style.css           # 样式文件
├── post1.html          # 文章1：JavaScript 闭包
├── post2.html          # 文章2：Python 数据分析
├── post3.html          # 文章3：React Hooks
├── post4.html          # 文章4：Docker
└── README.md
```

## 运行方式

直接打开 `index.html` 文件即可浏览，无需服务器环境。

## 部署

可以部署到任何静态网站托管服务，如：
- GitHub Pages
- GitCode Pages
- Netlify
- Vercel
